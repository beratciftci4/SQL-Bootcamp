# SQL Bootcamp

TurkStudentCo Data Science Bootcamp'te yaptığım haftalık SQL ödevleri. Hepsi PostgreSQL ile yazıldı. 2. ve 3. haftalarda Chinook örnek veritabanını kullandım.

| Klasör | Konu |
|---|---|
| [Hafta-1-Temel-Komutlar](Hafta-1-Temel-Komutlar) | SELECT, DISTINCT, WHERE, ORDER BY, metin birleştirme |
| [Hafta-2-Sorgulama-ve-Filtreleme](Hafta-2-Sorgulama-ve-Filtreleme) | NULL kontrolü, hesaplanmış sütunlar, LEFT/RIGHT, TO_CHAR ile tarih filtreleme |
| [Hafta-3-JOIN](Hafta-3-JOIN) | SUM/BETWEEN, LEFT JOIN, INNER JOIN ile çoklu tablo sorguları |

Her klasörde o haftanın sorgularını tek tek anlatan bir README var.

Bootcamp'in final projesi ayrı bir repoda: [sql-education-platform-project](https://github.com/beratciftci4/sql-education-platform-project)
